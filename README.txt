5 AM FITNESS HUB - PENSACOLA ATHLETIC CENTER

TO PUT ON YOUR IPHONE HOME SCREEN
1. Upload all files in this folder (not just index.html) to a static HTTPS website, such as GitHub Pages, Netlify or Cloudflare Pages.
2. Open the published HTTPS website in Safari on your iPhone.
3. Tap Share, then Add to Home Screen, then Add.
4. For a dependable 5 AM wake-up alert, use the iPhone Clock app to create a repeating Monday-Saturday alarm. The website itself cannot guarantee wake-up alerts when closed.

TO TRY IT NOW
Open index.html in a browser. Most tracking functions work as-is. For full offline/PWA installation support, publish over HTTPS.

Your data stays in local browser storage and will not automatically sync to other devices. Use Progress > Export backup to save it.
Equipment categories are based on the walkthrough video, not confirmed model numbers.
